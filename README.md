**Everything in this repo is visible to anyone on the internet.**

This `.github` repository exists so we can share organization-wide resources such as issue templates, pull request templates, and community health files across all of our repositories. GitHub requires it to be public for those defaults to work.

## Before you commit, ask yourself:

> **Would we be comfortable with this appearing on the front page of the internet?**

If the answer is anything other than a confident "yes," **do not put it here.**

## Never commit

- Secrets, API keys, tokens, passwords, or credentials
- Internal URLs, hostnames, IP addresses, or infrastructure details
- Customer, employee, or partner information
- Unreleased product plans, roadmaps, or strategy
- Internal process documentation, security procedures, or incident details
- Anything marked confidential, internal, or proprietary

## Remember

- **Git history is permanent.** Deleting a file in a later commit does not remove it from history. Anything committed here should be considered disclosed.
- **Forks and clones are outside our control.** Once content is public, it can be copied by anyone.
- **Review pull requests with this in mind.** Reviewers are responsible for catching anything that shouldn't be here.

## Accidentally committed something sensitive?

1. **Rotate or revoke** any exposed credentials immediately.
2. **Notify** the team through the appropriate channels. 
3. Do not try to quietly fix it alone. History rewriting may be needed and should be coordinated.

## Internal content belongs elsewhere

If it's not meant for the public, put it in a private repository or your internal documentation system.
